# Pixelio

Pixelio evaluates Habbo inventories, rooms, and unlocked wardrobe items.
Available in Brazilian Portuguese and English for Windows 10/11 x64.

## Download

Download **Pixelio.exe** from [Releases](https://github.com/CarlosPlacinta/Pixelio/releases).
You can also extract the portable ZIP and open Pixelio.exe. Python is not required.
Habbo and G-Earth are required for live scans.

From version 1.1.0, Pixelio checks for updates when it opens. Choose **Update now**
or **Later** when a new version is available. Saved scans and settings are kept.
Older versions need to be replaced with version 1.1.0 once to enable updates.

## Português

Baixe **Pixelio.exe** em [Releases](https://github.com/CarlosPlacinta/Pixelio/releases).
Também é possível extrair o ZIP e abrir Pixelio.exe. Não é necessário instalar Python.
Habbo e G-Earth são necessários para scans ao vivo.

A partir da versão 1.1.0, o Pixelio verifica atualizações ao abrir. Escolha
**Atualizar agora** ou **Mais tarde**. Seus scans e configurações são mantidos.

Os dados de cada usuário ficam em `%LOCALAPPDATA%\HabboInventoryScanner`.
Esta distribuição não inclui contas, scans ou configurações pessoais.
