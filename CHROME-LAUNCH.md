# Chrome launch retired

The optional Chrome launch flow was removed in Pixelio 1.3.20 at the user's request.

Use the original flow:

1. Click **Connect account** in Pixelio.
2. Complete the one-time Windows connection setup if prompted.
3. Enter **Habbo Classic (AIR)** manually.

No Chrome extension or Chrome Web Store setup is required. Old Chrome launch
preferences are ignored. Saved scans and accounts are preserved.

The Web Store item was a draft; it is not part of the current Pixelio connection
flow. The old extension privacy policy remains available for historical reference.
